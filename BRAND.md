# Refract Brand Assets

The Refract name and logos identify the official Refract project. This file
documents how the supplied logo variants are intended to be used; it does not
change the license that applies to the project's source code.

## Logo Variants

| Asset | Intended use |
|---|---|
| `assets/refract-v2-dark.png` | Primary logo on dark surfaces and for general project presentation. The README uses it in dark mode and as its fallback image. |
| `assets/refract-v2-light.png` | Inverted treatment for white or light surfaces, print, and light-theme documentation. The README uses it in light mode. |
| `assets/refract-v2-micro.png` | Simplified mark for 16–64 pixel uses such as favicons, project avatars, application icons, terminals, and compact navigation. Do not use it as the large README mark. |
| `assets/refract-v2-transparent-preview.png` | Design preview only. The current file is an RGB PNG with no alpha channel and contains a checkerboard background. Do not use it as a transparent web or document asset. |
| `assets/logo.png` | Preserved legacy asset. It remains available for historical compatibility but is not the default README mark. |

The dark and light files are theme treatments of the same mark, not separate
identities. Use the variant appropriate to the surrounding surface and keep
usage consistent within a page or document.

## Usage

- Preserve the original aspect ratio, orientation, colors, and clear space.
- Do not crop, stretch, rotate, redraw, or place the mark inside a decorative
  border.
- Do not add shadows, background gradients, or text inside the mark.
- Use the micro variant only where its simplified geometry improves small-size
  legibility.
- Do not present the transparent preview as an alpha-transparent asset. A
  future transparent logo must be verified to contain a real alpha channel
  before use.
